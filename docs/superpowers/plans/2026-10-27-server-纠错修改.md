## Task 1: `DBAdapter` 增加数据库连接（connect/close）

**Files:**
- Modify: `server/adapter/include/DBAdapter.h`
- Modify: `server/adapter/internal/InMemoryDbAdapter.h`
- Modify: `server/adapter/src/InMemoryDbAdapter.cpp`

在 `DBAdapter` 抽象接口中，`insert_user` 之前插入连接生命周期：

```cpp
    /**
     * @brief 建立数据库连接
     * @return 成功返回 true
     */
    virtual bool connect() = 0;

    /**
     * @brief 关闭数据库连接
     */
    virtual void close() = 0;
```

`InMemoryDbAdapter` 声明：

```cpp
    bool connect() override;
    void close() override;
```

`InMemoryDbAdapter` 实现（`connect` 初始化空存储、`close` 清空）：

```cpp
bool InMemoryDbAdapter::connect() {
    std::lock_guard<std::mutex> lock(mutex_);
    users_.clear();
    rooms_.clear();
    room_members_.clear();
    next_user_id_ = 1;
    spdlog::info("InMemoryDbAdapter: connected (in-memory store initialized)");
    return true;
}

void InMemoryDbAdapter::close() {
    std::lock_guard<std::mutex> lock(mutex_);
    users_.clear();
    rooms_.clear();
    room_members_.clear();
    next_user_id_ = 1;
    spdlog::info("InMemoryDbAdapter: closed (in-memory store cleared)");
}
```
